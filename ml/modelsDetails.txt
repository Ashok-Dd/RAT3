=============================================================
  Android Malware Detection – Stacking Ensemble Classifier
=============================================================
Dataset  : TUANDROMD.csv  (4465 samples, 241 binary features)
Target   : Label  →  malware / goodware

Stacking architecture:
  ┌─────────────── Level-0 Base Learners ──────────────────┐
  │  • Random Forest   (300 trees, tuned)                  │
  │  • Extra Trees     (300 trees, tuned)                  │
  │  • XGBoost         (gradient boosted trees, tuned)     │
  │  • Logistic Reg.   (L2, scaled input)                  │
  │  • KNN             (k=5, scaled input)                  │
  └──────────────────────────────────────────┬─────────────┘
                                             │ out-of-fold proba
                                             ▼
               Level-1 Meta-Learner: Logistic Regression
                   (learns how to best combine base outputs)

Fine-tuning:
  • GridSearchCV over meta-learner C (regularisation)
  • cross_val_score for base-learner selection
  • 5-fold stratified CV throughout

Generalisation tracking:
  • 5-fold CV train vs test per base learner
  • Learning curve on full stack
  • Confusion matrix + ROC
  • Generalisation dashboard
